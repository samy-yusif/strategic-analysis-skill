# مهارة التحليل الاستراتيجي لـ Claude

**جملة واحدة منك، وتطلع استراتيجية كاملة مبنية على بحث حقيقي: نموذج Excel وتقرير Word وعرض تقديمي مختصر.**

أكثر من 20 أداة تحليل استراتيجي مرتبة بالتسلسل الصحيح، ومع كل أداة حلول لزيادة فرص النجاح.

[English](README.md)

## ليه المهارة دي؟

أغلب أوامر "الاستراتيجية بالذكاء الاصطناعي" بتطلع SWOT عام وخلاص. لكن الإدارة الاستراتيجية الحقيقية سلسلة مترابطة: بحث، ثم فلترة العوامل، ثم أوزان، ثم مطابقة، ثم تقييم، ثم خطة بميزانية ومؤشرات أداء.

المهارة دي بتخلي Claude يمشي السلسلة كلها:

- **بيبحث بنفسه** عن بيانات الاقتصاد والصناعة والمنافسين وقوائمهم المالية.
- **كل أداة بتغذي اللي بعدها**، فمفيش حاجة في الخطة طالعة من فراغ.
- **مفيش تشخيص من غير حل**: كل تهديد أو ضعف ليه إجراء واضح، ومسؤول، وتكلفة، ومدة، والدرجة اللي بيحسّنها.
- **وضعين**: تحليل شركة قائمة، أو بناء مشروع جديد من الصفر. في المشروع الجديد الرؤية والرسالة بتتكتب بعد التحليل.

## المخرجات

| المخرج | المحتوى |
|---|---|
| **Excel** | حوالي 30 شيت مترابطة بمعادلات، مع عمود حلول في كل أداة |
| **تقرير Word** | شرح كامل لكل أداة: الغرض، الطريقة، النتائج، التفسير، الحلول، المصادر |
| **عرض تقديمي** | حوالي 20 شريحة تلخيص للموقف والقرار والخطة وأهم 10 حلول |

المخرجات حاليًا بالإنجليزية، وخيار الإخراج بالعربية موجود في خطة التطوير.

## التثبيت

**Claude.ai**: اضغط مجلد `skills/strategic-analysis` كملف zip، وبعدين ادخل على Settings ← Capabilities ← Skills ← Upload skill.

**Claude Code**:
```bash
git clone https://github.com/samy-yusif/strategic-analysis-skill.git
cp -r strategic-analysis-skill/skills/strategic-analysis ~/.claude/skills/
```
